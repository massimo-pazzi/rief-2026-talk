# Интерфейс энергетики будущего: доклад на РМЭФ-2026

Портфолио-кейс по стратегии и аналитике рынка: аналитическая записка и доклад
«Интерфейс энергетики будущего: как ИИ меняет способ взаимодействия человека
с энергетической инфраструктурой» на Российском международном энергетическом
форуме, Санкт-Петербург, 23 апреля 2026 года.

**Страница кейса:** [massimo-pazzi.github.io/rief-2026-talk](https://massimo-pazzi.github.io/rief-2026-talk/)
**Новость о выступлении:** [nanosemantics.ai/blog/807](https://nanosemantics.ai/blog/807)

## Структура

```
index.html              страница кейса (собирается скриптом)
report/case.md          текст кейса
scripts/build_page.py   сборка страницы, данные инфографики и источники
assets/img/             фото со сцены и аватар
```

## Как пересобрать

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_page.py
```
